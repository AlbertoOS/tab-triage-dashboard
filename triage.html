      Review your tabs

      • Sort: click column headers to add priorities: default direction → reverse → off. Title and Domain start A–Z; Age starts oldest first (time since last access).
      • Filter: age buckets match any selected bucket (OR); status requirements all apply (AND). Status buttons cycle off → include → exclude. Selected domains match any checked domain. No domains checked means all domains. Search and filter groups apply together.
      • Search: matches titles, URLs and domains; Fuzzy matches all words in any order. Escape clears search when Help is closed.
      • Ignore: hide a URL or domain via the row’s More menu. Show ignored only shows only ignored tabs, still subject to search and filters. Manage ignored lets you remove entries or reset the lists.
      • Group by: display clusters organize the dashboard list, not native browser tab groups.

      Close, export and restore

      • Dedup: keeps the clicked tab and closes other loaded copies of its normalized URL, including filtered-out and ignored tabs across windows. It does not protect other pinned or active copies.
      • Close selected: select individual rows or all filtered tabs, including collapsed clusters. Changing filters removes hidden rows from the selection. Dashboard tabs are excluded.
      • Export selected links: saves the selection; Export all links: saves all loaded tabs regardless of filters and ignores. Files contain one URL per line in current sort order. Duplicate URLs are preserved. Dashboard tabs and empty URLs are excluded. To export a filtered result, select all filtered tabs first.
      • Restore most recently closed tab/window: the browser chooses one tab or window session from browser-wide history per click; this is not an exact undo of your action or batch. Another closure can change the chosen session. Private tabs and sessions no longer retained may not be recoverable.

      Project, privacy and support

      Tab Triage Dashboard is open source (MIT). It has no application backend or analytics and does not upload your tab list. Preferences stay in local extension storage; site-icon loading can cause network requests. Exports contain browsing URLs: review them before sharing.

      Project Issues / support Releases Privacy policy

      Reporting an issue requires a GitHub login. Issues are public. Do not post private tab URLs, tab lists, exports or screenshots containing sensitive information. Use a minimal example with synthetic tabs instead.
